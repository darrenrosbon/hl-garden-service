# HL Garden Service

One page, mobile first preview site. Static HTML, no build step. Open `index.html` in a browser.

Services come from the owner's Google post and the logo on the listing: irrigation install and service, landscaping and lawn mowing, tree felling, paving, painting, electrical. The mark is a custom HL monogram inspired by the listing logo (their own logo is too detailed for the hero and small sizes). The hero cycles through six services, one image each. Photos: one from the listing (lawn with pool and paving), the rest Pexels stock. No people appear in the images. The listing's two pipework photos are deliberately not used.
